# Kalyan Pathlab — बुकिंग अ‍ॅप सेटअप गाईड

## १. ही फाईल्स कुठे टाकायच्या (होस्टिंग)

तुमची मुख्य वेबसाईट आधीच इथे आहे:
https://swapnilmokal.github.io/kalyan-pathlab/

ती ज्या GitHub रिपॉझिटरीमध्ये आहे (repo नाव: `kalyan-pathlab`, यूजरनेम: `swapnilmokal`)
त्याच रिपॉझिटरीमध्ये एक नवीन फोल्डर बनवा: **`book`**

त्या `book` फोल्डरमध्ये या सर्व फाईल्स टाका:
- index.html
- style.css
- app.js
- tests-data.js
- manifest.json
- sw.js
- icons/ (संपूर्ण फोल्डर — logo.png, qr.png, icon-192.png, icon-512.png)

GitHub वेबसाईटवरून (कोडिंगशिवाय) टाकायचं असेल तर:
1. https://github.com/swapnilmokal/kalyan-pathlab वर जा
2. "Add file" > "Upload files" क्लिक करा
3. फोल्डरचं नाव टाईप करून टाका: `book/index.html` (path टाईप करून टाकल्यास आपोआप फोल्डर तयार होतो)
4. सर्व फाईल्स याप्रमाणे अपलोड करा, "Commit changes" दाबा

२-३ मिनिटांत तुमचं बुकिंग अ‍ॅप इथे लाईव्ह होईल:
**https://swapnilmokal.github.io/kalyan-pathlab/book/**

मुख्य वेबसाईटवर एक "Book Now / ऑनलाइन बुकिंग करा" बटण टाकून त्याला या लिंकला जोडा,
म्हणजे दोन्ही साईट एकमेकांना जोडलेल्या राहतील (हे मी आधीच अ‍ॅपच्या फूटरमध्ये उलट दिशेने केलं आहे —
अ‍ॅपच्या शेवटी "मुख्य वेबसाईटवर परत जा" लिंक आहे).

## २. फोनवर अ‍ॅप सारखं इन्स्टॉल कसं करायचं

वरची लिंक Chrome/Safari मध्ये उघडा > ब्राउझरच्या मेनूमध्ये "Add to Home Screen" किंवा
"Install App" असा पर्याय दिसेल. तो दाबला की आयकॉनसकट होम स्क्रीनवर अ‍ॅप येईल.

## ३. बुकिंग आपोआप Sheet मध्ये + ईमेलवर येण्यासाठी (मोफत बॅकएंड)

`google-apps-script.gs` फाईलमध्ये पूर्ण सूचना दिलेल्या आहेत. थोडक्यात:
1. नवीन Google Sheet बनवा
2. Extensions > Apps Script मध्ये तो कोड पेस्ट करा
3. Web App म्हणून Deploy करा, मिळालेली लिंक कॉपी करा
4. `app.js` फाईलमध्ये सुरुवातीला `CONFIG.appsScriptUrl` मध्ये ती लिंक पेस्ट करा

यानंतर प्रत्येक बुकिंग आपोआप Sheet मध्ये सेव्ह होईल आणि तुम्हाला (kalyan.pathlab.21@gmail.com)
व ग्राहकाला (ईमेल दिला असल्यास) आपोआप ईमेल कन्फर्मेशन जाईल — पूर्ण मोफत.

## ४. WhatsApp बद्दल एक महत्त्वाची व खरी गोष्ट

- **तुम्हाला (लॅबला)** बुकिंगची माहिती WhatsApp वर मिळण्यासाठी: ग्राहक बुकिंग सबमिट केल्यावर
  WhatsApp आपोआप उघडतो, मेसेज आधीच तयार असतो — ग्राहकाने फक्त "Send" दाबायचं (१ टॅप). पूर्ण
  automatic (न ग्राहकाच्या हातात न पडता थेट पाठवणे) फक्त पेड "WhatsApp Business API" नेच शक्य
  आहे, जे फ्री नाही.
- **ग्राहकाला** बुकिंग कन्फर्मेशन आपोआप त्याच्या WhatsApp वर (काहीही न दाबता) पाठवणे — हे सुद्धा
  तांत्रिकदृष्ट्या फक्त पेड WhatsApp Business API नेच शक्य आहे. मोफत पर्याय म्हणून मी ईमेल
  कन्फर्मेशन पूर्ण automatic ठेवलं आहे (वर मुद्दा ३ पहा) — ग्राहकाने ईमेल दिला की त्याला लगेच
  मेल जातो, काहीही दाबावं लागत नाही.
- भविष्यात जर पूर्ण automatic WhatsApp हवं असेल, तर Gupshup, Interakt, किंवा WATI सारख्या
  सेवा वापरता येतील (यांचा खर्च साधारण ₹1000-3000/महिना पासून सुरू होतो).

## ५. टेस्ट व किमती कशा बदलायच्या

`tests-data.js` फाईल उघडा — प्रत्येक टेस्टची एक ओळ आहे:
`{ name: "टेस्टचं नाव", mrp: मूळ किंमत, price: सवलतीनंतरची किंमत }`
हवं तसं बदला, नवीन टेस्ट जोडा किंवा काढा — अ‍ॅपवर आपोआप अपडेट होईल.

## ६. रिव्ह्यूज कसे मॉडरेट करायचे

ग्राहकाने रिव्ह्यू सबमिट केल्यावर तो थेट वेबसाईटवर दिसत नाही (खोट्या/स्पॅम रिव्ह्यूपासून
सुरक्षेसाठी). तो आधी तुमच्या Google Sheet च्या "Reviews" टॅबमध्ये "Pending" स्टेटससोबत जमा होतो,
आणि तुम्हाला ईमेल सूचना मिळते. तो रिव्ह्यू वेबसाईटवर दाखवायचा असेल तर Sheet मध्ये त्या ओळीच्या
"Status" कॉलममध्ये फक्त **Approved** असं टाईप करा — काही वेळात तो वेबसाईटवर दिसू लागेल.
